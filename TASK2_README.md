# Task 2: Сравнение форматов ответов и логирование

## Описание задания

В этом задании реализованы следующие возможности:

1. **Отправка одного запроса с разными параметрами форматирования**
2. **Сравнение ответов с ограничениями и без**
3. **Логирование всех вопросов и ответов**

## Новые возможности

### 1. Режим сравнения

Введите команду `compare` в интерактивном режиме, чтобы отправить один запрос с четырьмя различными настройками:

#### Режим 1: Без ограничений
- Стандартный запрос без дополнительных параметров
- Базовая температура 0.7
- Нет ограничений на длину ответа

#### Режим 2: С явным форматом ответа
- **Системный промпт**: Требует ответ в формате JSON
- **Формат**: `{"answer": "...", "summary": "..."}`
- Демонстрирует структурированный вывод

#### Режим 3: С ограничением длины
- **Системный промпт**: Краткий ответ (2-3 предложения)
- **max_tokens**: 100
- Показывает влияние ограничения на токены

#### Режим 4: С условием завершения (stop sequence)
- **Системный промпт**: Завершать ответ словом "[КОНЕЦ]"
- **stop**: ["[КОНЕЦ]"]
- Демонстрирует использование stop sequence

### 2. Автоматическое логирование

Все взаимодействия автоматически сохраняются в папке `logs/`:

**Структура лога:**
```json
[
  {
    "timestamp": "2026-03-17T18:30:45.123456",
    "user_input": "Вопрос пользователя",
    "assistant_response": "Ответ ассистента",
    "usage": {
      "prompt_tokens": 50,
      "completion_tokens": 100,
      "total_tokens": 150,
      "cost": 0.000275
    },
    "metadata": {
      "mode": "normal"
    }
  }
]
```

**Имя файла**: `conversation_YYYYMMDD_HHMMSS.json`

### 3. Обновленный .gitignore

Логи автоматически исключены из git:
```
# Logs
logs/
*.log
```

## Использование

### Обычный режим
```bash
python3 llm_cli.py
You: Ваш вопрос
```

### Режим сравнения
```bash
python3 llm_cli.py
You: compare
Введите запрос для сравнения: Что такое машинное обучение?
```

После выполнения вы увидите:
1. Ответы во всех четырех режимах
2. Информацию о токенах и стоимости для каждого
3. Сводную таблицу сравнения

## Анализ результатов

При сравнении режимов обратите внимание на:

1. **Длину ответов** - как ограничения влияют на объем информации
2. **Количество токенов** - связь между длиной и стоимостью
3. **Формат ответа** - как системные промпты влияют на структуру
4. **Стоимость** - разницу в цене между режимами

## Технические детали

### Функции логирования

**`setup_logging()`**
- Создает папку `logs/`
- Генерирует уникальное имя файла с timestamp

**`log_interaction(log_file, user_input, assistant_response, usage_info, metadata)`**
- Сохраняет каждое взаимодействие в JSON
- Добавляет метаданные о режиме работы

**`compare_formatting_modes(client, user_input, log_file)`**
- Отправляет 4 запроса с разными параметрами
- Собирает статистику
- Логирует все ответы
- Выводит сводку

## Команды

- `quit`, `exit`, `q` - выход из программы
- `compare` - режим сравнения форматов
- Любой другой текст - обычный запрос к LLM

## Замечания

1. Все логи сохраняются локально и не попадают в репозиторий
2. Каждая сессия создает отдельный лог-файл
3. Режим сравнения не учитывается в общей статистике сессии
4. Стоимость рассчитывается для модели gpt-3.5-turbo
