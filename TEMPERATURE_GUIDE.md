# Руководство по сравнению температур

## Что такое температура в LLM?

**Temperature** — это параметр, контролирующий случайность и креативность ответов модели:

- **0** — детерминированные, точные, повторяемые ответы
- **0.7** — баланс между точностью и креативностью (стандарт)
- **1.2+** — высокая креативность, разнообразие, но меньше точности

## Поддержка температуры в моделях

### ✅ Поддерживают temperature
- **zai-org/GLM-4.7-Flash** (Cloud.ru) — рекомендуется для экспериментов
- **zai-org/GLM-4.7** (Cloud.ru)

### ❌ НЕ поддерживают temperature
- **gpt-5-nano** — параметр автоматически удаляется

## Использование

### Запуск сравнения

```bash
python3 llm_cli.py

You: temperature
Введите запрос для сравнения температур: Придумай короткую историю про робота
```

### Что происходит

Утилита выполнит **3 запроса** с одним и тем же промптом, но разными температурами:

1. **Temperature = 0** — самый детерминированный ответ
2. **Temperature = 0.7** — сбалансированный ответ
3. **Temperature = 1.2** — самый креативный ответ

### Результаты

После выполнения вы получите:

#### 1. Три разных ответа
Каждый с указанием характеристик температуры и статистикой (символы, слова, токены)

#### 2. Сводку сравнения
```
СВОДКА СРАВНЕНИЯ ТЕМПЕРАТУР
======================================================================

Temperature = 0:
  Символов: 450
  Слов: 95
  Токенов: 115

Temperature = 0.7:
  Символов: 520
  Слов: 110
  Токенов: 132

Temperature = 1.2:
  Символов: 580
  Слов: 125
  Токенов: 148
```

#### 3. Анализ и рекомендации

```
📊 Разброс метрик:
  Символы: 450 - 580 (разница: 130)
  Слова: 95 - 125 (разница: 30)

💡 РЕКОМЕНДАЦИИ ПО ИСПОЛЬЗОВАНИЮ:

🎯 Temperature = 0 (Детерминированная):
   ✓ Задачи требующие точности и повторяемости
   ✓ Технические объяснения, документация
   ✓ Извлечение фактов, классификация
   ✓ Когда нужен один правильный ответ

⚖️ Temperature = 0.7 (Сбалансированная):
   ✓ Универсальный вариант для большинства задач
   ✓ Диалоги, вопросы-ответы
   ✓ Объяснения с примерами
   ✓ Когда нужен баланс точности и естественности

🎨 Temperature = 1.2 (Креативная):
   ✓ Творческие задачи (рассказы, идеи)
   ✓ Brainstorming, генерация альтернатив
   ✓ Когда нужно разнообразие ответов
   ✓ Менее критичные задачи, где допустима вариативность

⚠️ ВАЖНО:
   • Высокая температура (>1.0) может давать менее точные ответы
   • Низкая температура (0) всегда даёт одинаковые ответы
   • Для критичных задач используйте temperature ≤ 0.3
   • Для креативных задач можно использовать temperature ≥ 1.0
```

## Примеры задач для экспериментов

### Задачи для temperature = 0 (точность)
- "Объясни что такое цикл for в Python"
- "Какая столица Франции?"
- "Переведи 'Hello World' на русский"
- "Классифицируй это как позитивный или негативный отзыв: ..."

### Задачи для temperature = 0.7 (баланс)
- "Как работает блокчейн?"
- "Объясни квантовую физику простыми словами"
- "Дай совет по карьере в IT"
- "Как приготовить пасту карбонара?"

### Задачи для temperature = 1.2 (креативность)
- "Придумай историю про космического путешественника"
- "Предложи 5 необычных идей для стартапа"
- "Напиши стихотворение про программирование"
- "Создай сценарий для короткого фильма"

## Критерии сравнения

При анализе результатов обращайте внимание на:

### 1. Точность
- **Temperature = 0**: Самая высокая, фактически правильные ответы
- **Temperature = 0.7**: Хороший баланс
- **Temperature = 1.2**: Может отклоняться от фактов ради креативности

### 2. Креативность
- **Temperature = 0**: Минимальная, шаблонные ответы
- **Temperature = 0.7**: Умеренная, естественный язык
- **Temperature = 1.2**: Максимальная, оригинальные формулировки

### 3. Разнообразие
- **Temperature = 0**: Нулевое — каждый раз один и тот же ответ
- **Temperature = 0.7**: Среднее — ответы похожи, но варьируются
- **Temperature = 1.2**: Высокое — каждый раз новый подход

### 4. Предсказуемость
- **Temperature = 0**: 100% предсказуемо
- **Temperature = 0.7**: Достаточно предсказуемо
- **Temperature = 1.2**: Низкая предсказуемость

## Практические выводы

### Когда использовать каждую настройку

| Задача | Температура | Почему |
|--------|-------------|--------|
| Техническая документация | 0 | Нужна точность и повторяемость |
| Извлечение данных из текста | 0-0.3 | Минимум интерпретаций |
| Чат-бот поддержки | 0.5-0.7 | Баланс точности и естественности |
| Генерация идей | 0.9-1.2 | Нужно разнообразие |
| Творческое письмо | 1.0-1.5 | Максимум креативности |
| Перевод | 0.3 | Точность важнее стиля |
| Резюме текста | 0.5 | Фактическая точность + читабельность |

### Типичные ошибки

❌ **Использовать высокую температуру для фактических вопросов**
```
Temperature = 1.2: "Столица Франции — это Лион или Марсель"
```

❌ **Использовать нулевую температуру для креатива**
```
Temperature = 0: "Жил-был робот. Он работал. Конец."
```

✅ **Правильный выбор температуры**
- Факты → 0
- Обычные задачи → 0.7
- Креатив → 1.2
