# Task 6 — News Agent CLI

AI-агент для автоматической генерации новостных постов на базе LLM.

---

## Архитектура

```
llm_cli.py                   ← точка входа (CLI)
news_agent/
    __init__.py
    roles.py                 ← системные промпты 5 ролей
    tools.py                 ← tool definitions + ToolDispatcher
    storage.py               ← PostStorage (файловое хранилище)
    formatter.py             ← OutputFormatter (md/html/telegram/json/plain)
    pipeline.py              ← NewsPipeline (5-шаговый конвейер)
    agent.py                 ← AgentLoop (ReAct-агент)
posts/
    index.json               ← индекс всех постов
    <id>/
        post.json            ← метаданные + контент
        post.md              ← Markdown-версия
```

---

## Два режима генерации

### 1. Pipeline (детерминированный, рекомендуется)

Последовательный конвейер из 5 этапов:

```
[1] PLANNER     → анализ темы, тип поста, угол подачи, структура
[2] RESEARCHER  → факты, статистика, контекст, ключевые участники
[3] WRITER      → написание черновика по плану и фактам
[4] EDITOR      → редактура, оценка качества (1-10), список правок
[5] SEO         → варианты заголовков, теги, мета-описание, хэштеги
```

Каждый этап — отдельный LLM-вызов с уникальным системным промптом и температурой.

### 2. Agent (автономный, ReAct-паттерн)

```
Thought → Action (tool call) → Observation → repeat → Final Answer
```

Агент сам решает порядок действий, вызывает инструменты через function calling API.

## Роли (Personas)

| Роль         | Температура | Назначение                                     |
|--------------|-------------|------------------------------------------------|
| `planner`    | 0.3         | Структура, угол подачи, целевая аудитория      |
| `researcher` | 0.4         | Факты, статистика, контекст                    |
| `writer`     | 0.75        | Написание текста поста                         |
| `editor`     | 0.3         | Редактура, оценка качества                     |
| `seo`        | 0.6         | Заголовки, теги, мета-описание                 |
| `autonomous` | 0.5         | Автономный агент (ReAct)                       |

---

## Типы постов

| Тип        | Описание              | Объём (слов) | Тон         |
|------------|-----------------------|--------------|-------------|
| `breaking` | Срочная новость       | 150–300      | urgent      |
| `analysis` | Аналитическая статья  | 500–800      | analytical  |
| `digest`   | Новостной дайджест    | 300–500      | neutral     |
| `social`   | Пост для соцсетей     | 80–200       | engaging    |
| `press`    | Пресс-релиз           | 400–600      | formal      |

---

## Инструменты агента (Function Calling)

| Инструмент        | Описание                                          |
|-------------------|---------------------------------------------------|
| `save_post`       | Сохраняет готовый пост в хранилище                |
| `load_post_history` | Загружает последние N постов                    |
| `analyze_topic`   | Анализирует тему (ключевые слова, тип, сложность) |
| `format_post`     | Конвертирует пост в нужный формат                 |
| `get_post_by_id`  | Загружает конкретный пост по ID                   |
| `check_duplicate` | Проверяет на дублирование темы                    |

---

## Команды CLI

```bash
python llm_cli.py
```

| Команда                        | Описание                                |
|--------------------------------|-----------------------------------------|
| `generate <тема>`              | Создать пост через pipeline             |
| `generate -t breaking <тема>`  | С указанием типа поста                  |
| `agent <тема>`                 | Автономный ReAct-агент                  |
| `batch <файл>`                 | Пакетная генерация из файла (1 тема/строка) |
| `history [n]`                  | Последние n постов (по умолчанию 10)    |
| `export <id> <формат>`         | Экспорт поста (md/html/telegram/json/plain) |
| `template list`                | Список типов постов                     |
| `template show <тип>`          | Описание конкретного типа               |
| `models`                       | Список доступных моделей                |
| `model <name>`                 | Переключить модель                      |
| `help`                         | Справка                                 |
| `quit` / `exit` / `q`          | Выход                                   |

## Примеры использования

```
news-agent> generate ЦБ повысил ключевую ставку до 21%

news-agent> generate -t analysis Влияние ИИ на рынок труда в 2025 году

news-agent> generate -t social OpenAI выпустила GPT-5

news-agent> agent Напиши дайджест новостей о криптовалютах за эту неделю

news-agent> history 5

news-agent> export a3f2b1c9 html

news-agent> template show breaking

news-agent> batch topics.txt
```

## Качество вывода

Редактор (`editor`-роль) выставляет оценку по 4 критериям:

- **clarity** — понятность изложения
- **accuracy** — точность формулировок
- **engagement** — вовлечённость читателя
- **structure** — логическая структура

Итоговый `quality_score` — среднее из 4 критериев (1–10).
