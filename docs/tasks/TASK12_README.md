# День 12. Персонализация ассистента

## Задача

Добавить персонализацию поверх модели памяти:
- Создать профиль пользователя
- Описать предпочтения (стиль, формат, ограничения)
- Подключить профиль к каждому запросу
- Проверить ответы для разных профилей

## Предустановленные профили

### Системный аналитик (`system_analyst`)

- **Стиль:** формальный, структурированный, технически точный
- **Тон:** деловой, нейтральный, аналитический
- **Формат:** списки, таблицы, нумерованные пункты, UML/BPMN нотация
- **Ограничения:** без расплывчатых формулировок, стандарты ГОСТ/IEEE, без эмодзи
- **Экспертиза:** требования к ПО, бизнес-анализ, UML, проектирование систем

### Журналист (`journalist`)

- **Стиль:** живой, яркий, увлекательный, storytelling
- **Тон:** энергичный, дружелюбный, профессиональный
- **Формат:** нарратив с подзаголовками, короткие абзацы, перевёрнутая пирамида
- **Ограничения:** объективность, проверка фактов, активный залог, без канцелярита
- **Экспертиза:** журналистика, копирайтинг, SMM, контент-стратегия

## Как работает персонализация

1. **Установка профиля** — `agent.set_profile(profile)` инжектирует предпочтения в `MemoryManager`
2. **Каждый запрос** — `build_system_prompt()` собирает system prompt:
   - Базовый промпт (инструкции агента)
   - `--- ПРОФИЛЬ ПОЛЬЗОВАТЕЛЯ ---` (стиль, формат, ограничения)
   - `--- ДОЛГОВРЕМЕННАЯ ПАМЯТЬ ---` (накопленные знания)
   - `--- РАБОЧАЯ ПАМЯТЬ ---` (текущая задача)
3. **Адаптация ответов** — LLM получает полный контекст и адаптирует стиль
4. **Запись в память** — агент сохраняет факты, решения, знания через блок `memory`
5. **Горячая смена** — профиль можно сменить без потери контекста диалога

## Демо-вопросы

Оба профиля отвечают на одни и те же вопросы:

1. «Что такое микросервисная архитектура и когда её стоит применять?»
2. «Расскажи о последних трендах в области искусственного интеллекта.»
3. «Как правильно организовать работу команды над сложным проектом?»

## Пример использования в коде

```python
from openai import OpenAI
from memory_agent import PersonalizedAgent, BUILTIN_PROFILES, MemoryManager

client = OpenAI(base_url="...", api_key="...")

# Создаём агента с профилем системного аналитика
profile = BUILTIN_PROFILES["system_analyst"]
memory = MemoryManager()
agent = PersonalizedAgent(
    client=client,
    model="zai-org/GLM-4.7",
    profile=profile,
    memory_manager=memory,
)

# Задаём вопрос — ответ адаптирован под профиль
answer = agent.chat("Что такое микросервисная архитектура?")
print(answer)

# Меняем профиль на журналиста — следующий ответ будет в другом стиле
agent.set_profile(BUILTIN_PROFILES["journalist"])
answer = agent.chat("Что такое микросервисная архитектура?")
print(answer)
```
