## Функциональные улучшения

### RAG
- Гибридный поиск (BM25 + векторный)
- Cross-encoder re-ranking
- Metadata filtering (дата, источник, теги)
- Streaming RAG-ответов
- Кэширование эмбеддингов

### Агентная система
- Multi-agent coordination (параллельная работа)
- Общая долгосрочная память между агентами
- Tool use с автоисправлением (retry при ошибке)
- LLM-based planning (вместо жёсткого FSM)
- Human-in-the-loop паузы

### MCP
- HTTP/SSE transport для remote серверов
- Аутентификация и авторизация инструментов
- Динамическое обнаружение серверов

### Наблюдаемость
- Structured logging (JSON-формат)
- Метрики: latency, token usage, error rate
- Dashboard мониторинга агентов
