# Справочник моделей OpenAI

## Доступные модели в утилите

### GPT-5 Nano (`gpt-5-nano`)
- **Название**: GPT-5 Nano
- **Описание**: Компактная версия GPT-5, оптимальное соотношение цены и качества
- **Стоимость**:
  - Prompt: $0.20 / 1M токенов ($0.0002 / 1K)
  - Completion: $1.25 / 1M токенов ($0.00125 / 1K)
  - Cached Input: $0.02 / 1M токенов (не реализовано в утилите)
- **Рекомендации**: Отличный выбор для большинства задач, дешевле gpt-4o-mini при сопоставимом качестве

### GPT-5.4 (`gpt-5.4`)
- **Название**: GPT-5.4
- **Описание**: Новейшая модель GPT-5, высокая производительность
- **Стоимость**:
  - Prompt: $2.50 / 1M токенов ($0.0025 / 1K)
  - Completion: $15.00 / 1M токенов ($0.015 / 1K)
  - Cached Input: $0.25 / 1M токенов (не реализовано в утилите)
- **Рекомендации**: Передовая модель для самых сложных задач, требует значительного бюджета

### GPT-3.5 Turbo (`gpt-3.5-turbo`)
- **Название**: GPT-3.5 Turbo
- **Описание**: Быстрая и экономичная модель
- **Стоимость**:
  - Prompt: $0.0015 / 1K токенов
  - Completion: $0.002 / 1K токенов
- **Рекомендации**: Оптимальна для большинства задач, хороший баланс цены и качества

### GPT-5.4 Mini (`gpt-5.4-mini`)
- **Название**: GPT-5.4 Mini
- **Описание**: Экономичная модель GPT-5 класса
- **Стоимость**:
  - Prompt: $0.75 / 1M токенов ($0.00075 / 1K)
  - Completion: $4.50 / 1M токенов ($0.0045 / 1K)
  - Cached Input: $0.08 / 1M токенов (не реализовано в утилите)
- **Рекомендации**: Хороший баланс цены и качества для GPT-5 класса

### GPT-4o (`gpt-4o`)
- **Название**: GPT-4o
- **Описание**: Оптимизированная GPT-4, баланс цены и качества
- **Стоимость**:
  - Prompt: $0.005 / 1K токенов
  - Completion: $0.015 / 1K токенов
- **Рекомендации**: Хороший выбор для сложных задач, требующих качества GPT-4

### GPT-4 Turbo (`gpt-4-turbo`)
- **Название**: GPT-4 Turbo
- **Описание**: Быстрая версия GPT-4
- **Стоимость**:
  - Prompt: $0.01 / 1K токенов
  - Completion: $0.03 / 1K токенов
- **Рекомендации**: Для задач, где важна скорость работы GPT-4

### GPT-4 (`gpt-4`)
- **Название**: GPT-4
- **Описание**: Наиболее мощная модель, высокая стоимость
- **Стоимость**:
  - Prompt: $0.03 / 1K токенов
  - Completion: $0.06 / 1K токенов
- **Рекомендации**: Для критически важных задач, где качество важнее стоимости

## Команды переключения

```bash
# Просмотр всех моделей
You: models

# Переключение на модель
You: model gpt-4o-mini

# Переключение на GPT-5 Nano (самая дешевая)
You: model gpt-5-nano

# Переключение на GPT-5.4
You: model gpt-5.4

# Переключение на GPT-4
You: model gpt-4
```

## Автоматический расчет стоимости

Утилита автоматически рассчитывает стоимость для каждой модели:
- Prompt токены умножаются на цену prompt для модели
- Completion токены умножаются на цену completion для модели
- Итоговая стоимость отображается в выводе

**Примечание**: Cached Input поддерживается OpenAI API, но пока не реализован в утилите. Все расчеты используют стандартные цены на input токены.

Все цены актуальны на март 2026 года согласно официальному прайс-листу OpenAI.
