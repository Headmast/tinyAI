# План улучшения качества ответов RAG

## Проблемы (на основе бенчмарка)
1. **0 цитат в ответах** — LLM не генерирует ЦИТАТЫ: блок
2. **Низкое доверие** — threshold 0.45, но многие вопросы на грани
3. **Температура 0.7** — слишком высокая для точных ответов

## Улучшения

### 1. Снижение температуры (quick win)
- Для RAG: 0.3 вместо 0.7
- Для цитат: 0.2 вместо 0.7
- Это делает ответы более детерминированными

### 2. Улучшение промпта для цитат
- Добавить пример формата
- Указать что цитаты ОБЯЗАТЕЛЬНЫ
- Упростить требования

### 3. Автоматическая генерация цитат
- Если LLM не вернул цитаты — извлечь ключевые предложения из чанков самим
- Верифицировать их против контекста

### 4. Увеличение контекста
- top_k: 10 для поиска
- top_k_before: 3 (соседние чанки)
- Это даст больше информации для ответа

### 5. Пост-обработка ответов
- Если quotes пустые — извлечь из чанков автоматически
- Проверить что inline [N] markers соответствуют реальным источникам

## Приоритет
1. Температура (5 мин)
2. Контекст (10 мин)
3. Промпт (15 мин)
4. Авто-цитаты (30 мин)
