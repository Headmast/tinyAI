# Task 3: Миграция на облачный провайдер Cloud.ru

## Описание задания

В этом задании выполнена миграция утилиты с OpenAI API на облачный провайдер **Cloud.ru Foundation Models API**.

## Ключевые изменения

### 1. Изменение провайдера API

**Было (OpenAI):**
```python
from openai import OpenAI

api_key = os.getenv("OPENAI_API_KEY")
client = OpenAI(api_key=api_key)
```

**Стало (Cloud.ru):**
```python
from openai import OpenAI

api_key = os.getenv("CLOUD_API_KEY")
base_url = "https://foundation-models.api.cloud.ru/v1"
client = OpenAI(api_key=api_key, base_url=base_url)
```

### 2. Изменение модели

**Было:** 7 моделей OpenAI (gpt-3.5-turbo, gpt-4o-mini, gpt-4o, gpt-4-turbo, gpt-4, gpt-5.4, gpt-5-nano)

**Стало:** 1 модель Cloud.ru
- `zai-org/GLM-4.7-Flash` - облачная модель GLM-4.7-Flash

### 3. Изменение расчета стоимости

GLM-4.7-Flash предоставляется **бесплатно**:
```python
"prompt_price": 0.0,
"completion_price": 0.0
```

## Использование

### Базовое использование

```bash
python3 llm_cli.py
```

### Доступные команды

Все команды из предыдущих версий сохранены:

- `quit` / `exit` / `q` - выход
- `compare` - сравнение всех режимов
- `modes` - показать список режимов
- `mode N` - переключиться на режим N (1-6)
- `models` - показать список моделей
- `model <name>` - переключиться на модель (в данной версии только одна модель)

### Режимы работы

Все 6 режимов работы сохранены:

1. **Без ограничений** - стандартный запрос
2. **С явным форматом ответа** - структурированный текст
3. **С ограничением длины** - max_completion_tokens=100
4. **С явной инструкцией завершения** - маркер [КОНЕЦ]
5. **С выводом в формате JSON** - JSON с полями answer, summary, key_points
6. **С метапромптингом** - двухэтапный процесс с автоопределением роли

## День 3: Разные способы рассуждения

### Новая команда: `reasoning`

Эта команда реализует задание "День 3" - сравнение четырех способов решения одной задачи.

### Использование

```bash
python3 llm_cli.py

You: reasoning
Введите задачу для сравнения способов рассуждения: У Маши было 15 яблок, она отдала 7 Пете. Сколько яблок осталось у Маши?
```

### 4 способа рассуждения

Система автоматически решает задачу четырьмя способами:

1. **Прямой ответ** - без дополнительных инструкций
   - Просто отправляет задачу как есть

2. **Пошаговое решение** - добавляет "Решай пошагово"
   - К задаче добавляется инструкция пошагового решения

3. **Метапромпт** - двухэтапный процесс:
   - Сначала модель создает оптимальный промпт для решения
   - Затем использует созданный промпт для решения

4. **Группа экспертов** - три роли:
   - **Аналитик**: анализ с точки зрения данных и логики
   - **Инженер**: техническая и практическая точка зрения
   - **Критик**: критическая оценка и поиск проблем
