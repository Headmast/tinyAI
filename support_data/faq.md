# FAQ — Служба поддержки TinyAI Platform

Документация по типовым вопросам и проблемам пользователей платформы TinyAI.

## Авторизация и аутентификация

### Как войти в систему?

Для входа в систему используйте email и пароль, указанные при регистрации.
Перейдите на страницу https://app.tinyai.example.com/login и введите ваши учётные данные.
Поддерживаются два метода входа: по email+пароль и через OAuth (Google, GitHub).

### Как зарегистрироваться?

1. Перейдите на https://app.tinyai.example.com/signup
2. Введите email, имя и пароль (минимум 8 символов, 1 цифра, 1 заглавная буква)
3. Подтвердите email по ссылке в письме (действительна 24 часа)
4. После подтверждения вы получите доступ к бесплатному тарифу (Free)

### Как настроить двухфакторную аутентификацию (2FA)?

1. Перейдите в Настройки → Безопасность → Двухфакторная аутентификация
2. Отсканируйте QR-код приложением-аутентификатором (Google Authenticator, Authy)
3. Введите 6-значный код для подтверждения
4. Сохраните резервные коды (10 одноразовых кодов) в надёжном месте

### Проблема: не работает авторизация

**Симптомы:** ошибка «Неверный email или пароль», «Аккаунт заблокирован», «Токен истёк».

**Решения:**

- **Неверный пароль:** нажмите «Забыли пароль?» на странице входа. На email придёт ссылка для сброса (действительна 1 час).
- **Аккаунт заблокирован:** аккаунт блокируется после 5 неудачных попыток входа. Разблокировка через 30 минут автоматически, или через ссылку в email.
- **Токен истёк:** токен авторизации действует 24 часа. Если вы получили ошибку 401 «Token expired» — выполните повторный вход или используйте refresh-токен.
- **2FA потерян:** если потеряно устройство с аутентификатором, используйте один из резервных кодов. Если резервные коды тоже утеряны — обратитесь в поддержку с паспортными данными аккаунта.

### Как сбросить пароль?

1. Перейдите на https://app.tinyai.example.com/forgot-password
2. Введите email, привязанный к аккаунту
3. Проверьте почту (включая папку «Спам»)
4. Перейдите по ссылке в письме (действительна 1 час)
5. Задайте новый пароль

Если письмо не приходит — проверьте, что email введён верно, или обратитесь в поддержку.

## Управление подпиской и оплата

### Какие тарифные планы доступны?

| Тариф | Цена | Лимит запросов | Функции |
|---|---|---|---|
| Free | $0/мес | 100 запросов/день | Базовый RAG, 1 проект |
| Pro | $29/мес | 5,000 запросов/день | Продвинутый RAG, 10 проектов, API-доступ, приоритетная поддержка |
| Enterprise | $99/мес | Безлимит | Все функции, SSO, SLA 99.9%, выделенный менеджер |

### Как изменить тарифный план?

1. Перейдите в Настройки → Подписка
2. Выберите новый тариф и нажмите «Изменить план»
3. При апгрейде — разница списывается пропорционально оставшимся дням
4. При даунгрейде — новый тариф вступает в силу со следующего периода

### Какие способы оплаты поддерживаются?

- Банковские карты: Visa, Mastercard, МИР
- PayPal
- Банковский перевод (только для Enterprise)

### Проблема: ошибка при оплате

**Симптомы:** «Карта отклонена», «Ошибка платежа», «Двойное списание».

**Решения:**

- **Карта отклонена:** проверьте баланс карты, срок действия, лимиты на интернет-платежи. Если карта МИР — убедитесь, что включены онлайн-платежи в мобильном банке.
- **Двойное списание:** если деньги списались дважды, напишите в поддержку с указанием дат и сумм. Возврат обрабатывается в течение 5-10 рабочих дней.
- **Не применился промокод:** промокод нужно ввести до нажатия кнопки оплаты. Проверьте срок действия промокода. Один промокод — один аккаунт.

### Как отменить подписку?

1. Настройки → Подписка → Отменить подписку
2. Доступ сохраняется до конца оплаченного периода
3. Данные хранятся 90 дней после отмены

## API-доступ

### Как получить API-ключ?

1. Перейдите в Настройки → API
2. Нажмите «Создать новый ключ»
3. Скопируйте ключ (показывается только один раз!)
4. Добавьте в заголовок: `Authorization: Bearer YOUR_API_KEY`

API-доступ доступен на тарифах Pro и Enterprise.

### Лимиты API

| Тариф | Rate limit | Макс. размер запроса |
|---|---|---|
| Pro | 60 запросов/мин | 10 MB |
| Enterprise | 300 запросов/мин | 50 MB |

### Проблема: ошибки API

**Типичные ошибки:**

- **401 Unauthorized:** API-ключ невалиден или истёк. Создайте новый ключ в Настройках → API.
- **403 Forbidden:** функция недоступна на вашем тарифе. Обновите тариф до Pro или Enterprise.
- **429 Too Many Requests:** превышен rate limit. Подождите 60 секунд или используйте экспоненциальный backoff. Заголовок `Retry-After` указывает время ожидания.
- **500 Internal Server Error:** ошибка на стороне сервера. Повторите запрос через 30 секунд. Если проблема повторяется — обратитесь в поддержку.
- **413 Payload Too Large:** размер запроса превышает лимит тарифа.

### Пример использования API

```bash
curl -X POST https://api.tinyai.example.com/v1/query \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "Как работает RAG?", "top_k": 5}'
```

### Версионирование API

Текущая версия: v1. Формат URL: `https://api.tinyai.example.com/v1/...`
При выпуске новой версии старая поддерживается минимум 12 месяцев.

## Интеграции

### Какие интеграции поддерживаются?

- **Вебхуки (Webhooks):** уведомления о событиях на указанный URL
- **Telegram-бот:** управление через @TinyAIBot
- **Slack:** приложение TinyAI для Slack-каналов
- **GitHub:** автоматический code review через GitHub Actions

### Как настроить вебхук?

1. Настройки → Интеграции → Вебхуки
2. Укажите URL эндпоинта (HTTPS обязателен)
3. Выберите события: query_completed, error, limit_reached
4. Скопируйте секрет для проверки подписи

Вебхуки отправляются с заголовком `X-TinyAI-Signature` для верификации.

### Проблема: интеграция не работает

**Решения:**

- **Вебхук не доставляется:** проверьте, что URL доступен извне (не localhost), сервер возвращает 200 OK, SSL-сертификат валиден. Логи доставки доступны в Настройки → Интеграции → Логи.
- **Telegram-бот не отвечает:** убедитесь, что бот запущен (/start), проект привязан (/connect PROJECT_ID). Перезапустите бота: /restart.
- **Slack не подключается:** переустановите приложение TinyAI из Slack App Directory. Проверьте разрешения (scopes): chat:write, channels:read.
- **SSL ошибка:** убедитесь, что ваш сервер использует валидный SSL-сертификат (не самоподписанный). Let's Encrypt — бесплатный вариант.

## Данные и хранение

### Лимиты хранения

| Тариф | Документы | Общий объём |
|---|---|---|
| Free | 50 документов | 100 MB |
| Pro | 1,000 документов | 5 GB |
| Enterprise | Безлимит | 50 GB |

### Как загрузить документы?

1. Перейдите в раздел «Документы» вашего проекта
2. Нажмите «Загрузить» или перетащите файлы
3. Поддерживаемые форматы: .md, .txt, .pdf, .docx, .html
4. После загрузки документы автоматически индексируются (1-5 минут)

### Как экспортировать данные?

Настройки → Данные → Экспорт. Доступные форматы: JSON, CSV.
Экспорт включает: документы, историю запросов, настройки проекта.
Обработка экспорта занимает до 30 минут для больших объёмов.

### Проблема: потеря данных

**Решения:**

- **Случайное удаление документа:** удалённые документы перемещаются в корзину и хранятся 30 дней. Корзина → выбрать документ → Восстановить.
- **Не сохранились изменения:** проверьте стабильность интернет-соединения. Все изменения сохраняются автоматически каждые 30 секунд. Предыдущие версии доступны в истории документа (последние 50 версий).
- **Конфликт версий:** при одновременном редактировании двумя пользователями система покажет диалог выбора версии. Выберите актуальную или объедините вручную.

### Как сделать бэкап?

Автоматические бэкапы выполняются ежедневно (Enterprise) или еженедельно (Pro).
Ручной бэкап: Настройки → Данные → Создать бэкап.

## Уведомления

### Типы уведомлений

- **Email:** отчёты об использовании, предупреждения о лимитах, новости
- **Push-уведомления:** в браузере (Chrome, Firefox) — результаты запросов, ошибки
- **Webhook:** программные уведомления (для интеграций)

### Как настроить уведомления?

Настройки → Уведомления:
- Включить/выключить каждый тип отдельно
- Выбрать частоту email-дайджестов: мгновенно, ежедневно, еженедельно
- Задать тихие часы (не отправлять push с 22:00 до 8:00)

### Как отписаться от рассылки?

- Ссылка «Отписаться» внизу каждого email
- Или: Настройки → Уведомления → снять все галочки

## Командная работа

### Роли и права доступа

| Роль | Права |
|---|---|
| Owner | Полный доступ, управление подпиской, удаление проекта |
| Admin | Управление участниками, настройки проекта |
| Editor | Загрузка документов, запросы, редактирование |
| Viewer | Только чтение и запросы |

### Как пригласить участника?

1. Проект → Настройки → Команда → Пригласить
2. Введите email участника
3. Выберите роль
4. Участник получит email с приглашением (действительно 7 дней)

### Проблема: нет доступа к проекту

**Решения:**

- **Не пришло приглашение:** проверьте папку «Спам». Попросите владельца проекта отправить приглашение повторно.
- **Нет прав на действие:** обратитесь к администратору проекта для повышения роли.
- **Аккаунт не в команде:** возможно, приглашение было отправлено на другой email. Проверьте, каким email вы авторизованы.

## Производительность и лимиты

### Типичное время ответа

| Операция | Среднее время |
|---|---|
| RAG-запрос (до 100 документов) | 1-3 секунды |
| RAG-запрос (до 1000 документов) | 3-8 секунд |
| Индексация документа | 5-30 секунд |
| Полная переиндексация | 1-10 минут |

### Проблема: медленная работа

**Решения:**

- **Таймаут запроса:** если запрос не завершился за 30 секунд, сервер вернёт ошибку 504. Упростите запрос или уменьшите top_k.
- **Долгий ответ API:** проверьте статус платформы на https://status.tinyai.example.com. Если это массовая проблема — мы уже работаем над ней.
- **Медленная индексация:** большие документы (>1 MB) индексируются дольше. Разбейте на несколько файлов для ускорения.
- **Heavy-запросы:** запросы с top_k > 20 или сложной фильтрацией занимают больше времени. Оптимизируйте параметры.

### Лимиты тарифа

Если вы превысили лимит запросов:
1. Текущие лимиты видны в Настройки → Подписка → Использование
2. Лимит сбрасывается ежедневно в 00:00 UTC
3. Для увеличения лимита — обновите тариф
4. Enterprise-клиенты могут запросить индивидуальный лимит через менеджера
