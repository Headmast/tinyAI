# Руководство по настройке и начало работы (Getting Started)

## Регистрация

1. Перейдите на https://app.tinyai.example.com/signup
2. Заполните форму: email, имя, пароль
3. Подтвердите email (ссылка в письме, действительна 24 часа)
4. Войдите в систему

## Первые шаги

### Шаг 1: Создание проекта

После входа вы окажетесь на панели управления.

1. Нажмите «+ Новый проект»
2. Укажите название (например «База знаний отдела»)
3. Выберите стратегию индексации:
   - **Structure** (рекомендуется) — для Markdown-документов
   - **Fixed size** — для неструктурированного текста
4. Нажмите «Создать»

### Шаг 2: Загрузка документов

1. Откройте проект → «Документы»
2. Нажмите «Загрузить» или перетащите файлы
3. Форматы: .md, .txt, .pdf, .docx, .html
4. Дождитесь индексации (статус: «Индексируется» → «Готово»)

### Шаг 3: Первый запрос

1. Перейдите на вкладку «Запросы»
2. Введите вопрос в поле поиска
3. Нажмите «Спросить» или Enter
4. Получите ответ с источниками

### Шаг 4: Настройка API (для разработчиков)

1. Настройки → API → «Создать ключ»
2. Скопируйте ключ (показывается один раз!)
3. Используйте в заголовке: `Authorization: Bearer YOUR_KEY`

## Рекомендации по подготовке документов

### Структура

- Используйте заголовки `#`, `##`, `###` для разделения тем
- Один файл — одна тема (лучше 10 файлов по 500 слов, чем 1 файл на 5000 слов)
- Списки и таблицы хорошо индексируются

### Формат

- **Markdown** (.md) — лучший формат (сохраняет структуру)
- **TXT** — для простого текста без структуры
- **PDF** — работает, но качество зависит от текстового слоя

### Что НЕ нужно загружать

- Сканы документов без OCR (пустой текстовый слой)
- Таблицы Excel (используйте описание в текстовом формате)
- Бинарные файлы (изображения, видео)
- Очень короткие файлы (< 50 слов — мало контекста)

## Настройка команды

### Приглашение участников

1. Проект → Настройки → Команда
2. Нажмите «Пригласить»
3. Введите email и выберите роль:
   - **Admin** — управление проектом и командой
   - **Editor** — загрузка документов и запросы
   - **Viewer** — только чтение и запросы
4. Участник получит email с приглашением (7 дней на принятие)

## Настройка уведомлений

### Email-уведомления

Настройки → Уведомления → Email:
- **Мгновенные** — получать сразу при событии
- **Дайджест** — 1 раз в день (утром) или 1 раз в неделю (понедельник)
- **Выключено** — не получать

### Push-уведомления

Доступны в Chrome и Firefox:
1. Настройки → Уведомления → Push
2. Разрешите уведомления в браузере
3. Выберите события: ошибки, завершение индексации, лимиты

### Тихие часы

Настройте период, когда push не отправляются:
- По умолчанию: 22:00 — 08:00 (ваш часовой пояс)
- Настраивается в Уведомления → Тихие часы

## Миграция с другой платформы

### Из Notion

1. Экспортируйте страницы из Notion в Markdown
2. Загрузите .md файлы в проект TinyAI
3. Переиндексируйте

### Из Confluence

1. Экспортируйте пространство в HTML или PDF
2. Конвертируйте в Markdown (рекомендуется markdownify)
3. Загрузите в проект

### Из Google Docs

1. Файл → Скачать → Обычный текст (.txt) или Веб-страница (.html)
2. Загрузите в проект TinyAI

## Лучшие практики

1. **Регулярно обновляйте документацию** — устаревшие данные снижают качество ответов
2. **Используйте структуру** — заголовки, списки, таблицы помогают RAG точнее находить информацию
3. **Тестируйте запросы** — после загрузки проверьте 5-10 типичных вопросов
4. **Мониторьте метрики** — если score < 0.5, добавьте больше документации по теме
5. **Разделяйте проекты** — разные темы = разные проекты (лучше релевантность)
